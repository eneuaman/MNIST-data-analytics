# MNIST Digit Classification

This project was developed as part of the "Artificial Intelligence" module during my Master's degree in Data Analytics (M.Sc.) at Justus-Liebig-University Giessen.

## Project Overview
The goal of this project is to build a Deep Learning model capable of recognizing and classifying handwritten digits (0-9) using the classic MNIST dataset. 

## Key Skills & Methods applied:
- Multiclass Classification for Image Data.
- Designing, training, and evaluating Neural Networks (Deep Learning).
- Utilizing modern AI frameworks such as Keras and Scikit-learn.
- Model optimization and performance metrics evaluation.
